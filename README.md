# 🍳 Что приготовить - PWA приложение

Веб-приложение для подбора рецептов на основе продуктов из холодильника.

## ✨ Возможности

- 📱 **PWA** - устанавливается на телефон как обычное приложение
- 🥘 **База рецептов** - популярные блюда с пошаговыми инструкциями
- ✅ **Выбор продуктов** - отмечаете что есть в холодильнике
- 🔍 **Умный поиск** - находит рецепты по доступным ингредиентам
- 📴 **Оффлайн режим** - работает без интернета
- 🎨 **Красивый UI** - адаптивный дизайн для мобильных

## 🚀 Установка

### Как PWA (рекомендуется)

1. Откройте приложение в браузере
2. Нажмите "Добавить на главный экран"
3. Используйте как обычное приложение

### Локальный запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/aartem2409a-pixel/what-to-cook.git
cd what-to-cook

# Запустите локальный сервер (нужен для PWA)
python -m http.server 8000

# Откройте в браузере
open http://localhost:8000
```

## 📖 Использование

1. **Выберите продукты** - нажмите на продукты, которые есть у вас
2. **Посмотрите рецепты** - приложение покажет что можно приготовить
3. **Фильтруйте** - используйте фильтры для точного подбора
4. **Готовьте** - следуйте пошаговым инструкциям

## 🛠 Технологии

- HTML5 + CSS3 + Vanilla JavaScript
- Progressive Web App (PWA)
- Service Worker для оффлайн работы
- LocalStorage для сохранения данных

## 📱 Скриншоты

Приложение адаптировано для мобильных устройств и работает как нативное приложение после установки.
